About Workspace
⚡
x0s Workspace
A full in-browser development environment.
Write, preview, save and deploy — all in one place.
HOW IT WORKS
Architecture (Editor)
Write code in any language — HTML, CSS, JS, Python, JSON, Markdown and more. Syntax is colour-highlighted and line counts update live.
Deploy
Hit Deploy to instantly render your code. HTML/CSS previews in the frame, JavaScript executes in a sandbox with console output, JSON validates and pretty-prints, Markdown renders to HTML.
Mobile View
Preview your build inside a real phone frame. The entire UI hides so the phone fills the screen. Tap back to return to the editor.
Save & Build History
Save any file with the correct extension auto-applied. Every saved build is logged in Build History — restore, download, or add to a repo with the three-dot menu.
Quick Repo
Group multiple files + media into a repo. Deploy the whole repo at once — x0s rewrites all asset references so your CSS, JS and images all load together, just like a real server.
